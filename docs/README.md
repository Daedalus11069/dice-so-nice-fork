# Dice So Nice! - Documentation

Documentation website for [Dice So Nice!](https://gitlab.com/riccisi/foundryvtt-dice-so-nice), the 3D dice module for Foundry VTT.

Built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build).

## Development

```sh
npm install
npm run dev
```

The dev server runs at `localhost:4321`.

## Build

```sh
npm run build
```

Output goes to `public/` (deployed to GitLab Pages).

## Structure

- `src/content/docs/guide/` - User guide
- `src/content/docs/api/` - Developer guide
- `src/assets/` - Images
- `static/` - Static assets (favicons, etc.)
